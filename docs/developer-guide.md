# 🪓 WorldEdit: Native Minestom Block Manipulation Engine

> **In-Memory Mathematical Block Transformations, Session History, and Schematic Management.**  
> *Hard-proof documentation for `libs/worldedit` and `libs/worldedit-core`.*

---

## ⚡ 1. Overview

* **`WorldEdit.kt`**: Minestom command hooks (`//set`, `//copy`, `//paste`, `//wand`, `//undo`, `//redo`).
* **`LocalSession.kt`**: Per-player clipboard storage, 3D cuboid selection tracking, and undo/redo history buffers.
* **`SelectionVisualizer.kt`**: Client-side particle visualizer rendering bounding box selections in real time.
